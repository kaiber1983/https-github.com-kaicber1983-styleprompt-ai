# StylePrompt AI

StylePrompt AI is an AI visual design workspace for creators who want a more personal art style and more distinctive original characters.

The product is being built around one core pain point:

> AI creators can generate images, but their art style and character design often feel generic, inconsistent, and hard to reuse.

## Product Direction

The first version focuses on two lightweight creator workflows:

- **Style DNA**: a guided diagnostic flow that turns a creator's mood, taste, visual preferences, and creative goal into a reusable personal art style system.
- **Character Kit**: an original character design generator that turns the Style DNA into a character concept, visual rules, story details, and multi-model prompts.

The style library is not the center of the product. It supports inspiration and calibration, while the main product experience helps users build their own visual identity.

## Target User

The first target user is:

- AI drawing creators.
- Self-media creators.
- Personal IP builders.
- Creators who publish visual content on Xiaohongshu, X, Pinterest, Instagram, TikTok, or YouTube Shorts.

The MVP does not prioritize ecommerce teams, game studios, enterprise brand systems, team collaboration, or image-to-3D.
